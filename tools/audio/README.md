# קבצי השמע של "להאזין"

הטקסט באפליקציה נשאר בלי ניקוד. הניקוד משמש רק להקראה.

1. `node extract.js ../../index.html items.json`: שולף את הפריטים היומיים. המפתח של כל פריט הוא sha1 של `t|x|a`.
2. `node nakdan.js items.json nik.json`: ניקוד אוטומטי בנקדן של דיקטה.
3. `node fix.js`: תיקונים ידניים לניקוד, שנבדקו פריט אחר פריט (בעיקר צורות ציווי). התוצאה נשמרת ב-`nik_fixed.json`, שהוא המקור של ההקראה.
4. `node gen.js`: מפיק קבצי MP3 ב-Azure Speech (he-IL-HilaNeural, he-IL-AvriNeural) לתוך `out/`, ואותם מעתיקים ל-`docs/audio/`.
5. מעדכנים את `AUDIO_KEYS` ב-`index.html` לפי המפתחות.

בשלבים 2 ו-4 צריך להריץ את node עם `NODE_USE_ENV_PROXY=1`. מפתח Azure לא נשמר בקוד: ה-proxy של הסביבה מזריק אותו.
פריט שהנוסח שלו השתנה מקבל מפתח חדש. עד שמפיקים לו שמע מחדש, הכפתור "להאזין" לא מופיע אצלו.
