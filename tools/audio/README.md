# קבצי השמע של "להאזין"

הקולות הם דלית ונמרוד מהספרייה של ElevenLabs, במודל eleven_v3. ההקראה נעשית מהטקסט של האפליקציה כמו שהוא, בלי ניקוד, כי בבדיקה זה נשמע טבעי יותר.

1. `node extract.js ../../index.html items.json`: שולף את הפריטים היומיים. המפתח של כל פריט הוא sha1 של `t|x|a`, 10 התווים הראשונים.
2. `node gen_el.js`: מפיק MP3 לכל פריט ולכל קול לתוך `out_el/`, ואותם מעתיקים ל-`docs/audio/`. צריך מסלול ElevenLabs בתשלום: במסלול החינמי ה-API לא מאפשר את קולות הספרייה. כל קול צורך כ-23 אלף תווים.
3. מעדכנים את `AUDIO_KEYS` ב-`index.html` לפי המפתחות, ומפרסמים מחדש את האפליקציה ב-claude.ai, כולל קבצי השמע ב-`files`.

את node צריך להריץ עם `NODE_USE_ENV_PROXY=1`. מפתח ה-API לא נשמר בקוד: ה-proxy של הסביבה מזריק אותו.
פריט שהנוסח שלו השתנה מקבל מפתח חדש. עד שמפיקים לו שמע מחדש, הכפתור "להאזין" לא מופיע אצלו.

מילה שנשמעת לא נכון אפשר לנקד רק בתוך הטקסט שנשלח להקראה, כלומר בתוך gen_el.js, ולהפיק מחדש רק את הפריט הזה.
`nakdan.js`, `fix.js` ו-`nik_fixed.json` נשארו מהניסיון עם Azure: ניקוד מלא שנבדק ידנית. אפשר להיעזר בהם כשצריך לנקד מילה בודדת.

## התבוננויות מודרכות
`node gen_guided.js ../../index.html` מפיק קובץ לכל שלב (שלבים זהים משותפים לכמה התבוננויות) בשני הקולות, וכותב את המפתחות ל-`guided_keys.txt`. את המפתחות מוסיפים ל-`AUDIO_KEYS`.
