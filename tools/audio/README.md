# קבצי השמע של "להאזין"

הקולות הם דלית ונמרוד מהספרייה של ElevenLabs, במודל eleven_v3. ההקראה נעשית מהטקסט של האפליקציה כמו שהוא, בלי ניקוד, כי בבדיקה זה נשמע טבעי יותר.

1. `node gen_all.js ../../index.html` מפיק כל קובץ חסר: כל רעיון יומי (המאגר, החודשים, חנוכה, העומר והחגים) וכל שלב בהתבוננויות המודרכות. כל פריט מוקלט בלשון זכר ובלשון נקבה (לפי `FEM` ב-index.html), ובשני הקולות. קבצים שכבר קיימים מדולגים. המפתח הוא 10 התווים הראשונים של sha1 של הטקסט המוקרא, והרשימה נכתבת ל-`all_keys.txt`. אפשר להוסיף `--dry` כדי לראות רק כמה חסר.
2. מעתיקים את `out_el/` ל-`docs/audio/`, ומעדכנים את `AUDIO_KEYS` ב-`index.html` לפי `all_keys.txt`.
3. מפרסמים מחדש את האפליקציה ב-claude.ai, עם קבצי השמע החדשים ב-`files`.

צריך מסלול ElevenLabs בתשלום: במסלול החינמי ה-API לא מאפשר את קולות הספרייה.
את node צריך להריץ עם `NODE_USE_ENV_PROXY=1`. מפתח ה-API לא נשמר בקוד: ה-proxy של הסביבה מזריק אותו.
פריט שהנוסח שלו השתנה מקבל מפתח חדש. עד שמפיקים לו שמע מחדש, הכפתור "להאזין" לא מופיע אצלו.

מילה שנשמעת לא נכון אפשר לנקד רק בתוך הטקסט שנשלח להקראה, כלומר ב-`fixes.js` (ראו בהמשך), ולהפיק מחדש רק את הפריט הזה.
`nakdan.js`, `fix.js` ו-`nik_fixed.json` נשארו מהניסיון עם Azure: ניקוד מלא שנבדק ידנית. אפשר להיעזר בהם כשצריך לנקד מילה בודדת.

## תיקוני הגייה
`fixes.js` מנקד מילים שקול מסוים קורא לא נכון, ורק בטקסט שנשלח להקראה. עד עכשיו יש תיקון אחד: דלית קראה "שאל" כ"שָׁאַל", ועכשיו היא מקבלת "שְׁאַל". אחרי שמוסיפים כלל, מוחקים מ-`out_el/<voice>/` את הקבצים שהכלל משנה ומריצים שוב את הסקריפטים. הם מפיקים רק קבצים שחסרים.
