# מנגינת החיים

אפליקציה לעבודה פנימית יומית, לפי מודל הנפש של ספר התניא.

- `index.html` — קוד האפליקציה (מקור).
- `docs/` — הגרסה שמתקינים בטלפון (נבנית מ-`index.html` עם `python3 build.py`).
- `SPEC.md` — האפיון.
- `CLAUDE.md` — הנחיות להמשך פיתוח.

## התקנה בטלפון
פותחים את כתובת האתר בטלפון. באייפון: Safari ← שיתוף ← "הוספה למסך הבית". באנדרואיד: Chrome ← תפריט ← "התקנת אפליקציה".
